KYC Security Lab - Offline Mock Training Demo

Run:
1. Extract the ZIP into a new folder.
2. Keep index.html and the media folder together.
3. Open index.html in a modern browser such as Chrome or Edge.

This is a local training simulation only. Permission prompts are simulated; it does not access a real camera, microphone, or KYC service.

Recent UI changes:
- Removed the on-video dialogue/caption overlay.
- Video transitions now hold the current frame while the next clip loads, then crossfade into the next clip instead of fading to black.
- Includes the latest supplied head-turn clip and audio recordings.

If media does not play when opened directly, try serving the folder with a local static web server.
